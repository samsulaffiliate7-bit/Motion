# BANK TOPIK (60 per akun)

Cukup untuk ~30 hari dengan jadwal 2 video/hari/akun. Format: **topik** — hook (teks frame pertama + kalimat pembuka narasi).

Aturan pakai:
- Tandai `[x]` setelah dipakai dan tulis tanggal + id episode. Jangan ulang topik yang sudah tayang di akun yang sama.
- Selang-seling pilar supaya feed tidak monoton (jangan dua topik dari pilar yang sama berturut-turut).
- Angka di hook hanya contoh; angka final dihitung di `episode.py`.
- Topik bertanda **[cek sumber]** butuh fakta/aturan nyata. Riset dulu, simpan sumber di file episode, tanya pemilik kalau perlu penegas.
- Bank ini ditambah terus. Ide dari komentar penonton dicatat di bagian "Usulan penonton" tiap akun.
