# Motion 6 Akun

Pipeline video pendek 9:16 untuk 6 akun faceless (Dompet Gue Nangis, Kades Magang Juara, Hewan Berdasi Kotor, Balai Desa Bocor, Denah Rumah Dunia, Meja Seberang Bos): narasi Gemini TTS + animasi 3D low-poly, diposting lewat Repliz.

- `CLAUDE.md`: aturan kerja dan keputusan pemilik.
- `docs/`: profil akun, konsep (v2 visual, v3 isi), bank topik, jadwal posting.
- `motion/`: mesin dan episode, cara pakai di `motion/README.md`.
